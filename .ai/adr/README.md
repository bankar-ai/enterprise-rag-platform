# .ai/adr/

Purpose: accepted architecture decisions. One file per decision, capturing the context, alternatives considered, and the decision made.

The ADR format and first entry ("ADR-001: Adopt Architecture Decision Records") are defined in **ERP-003 — ADR Framework**. No ADR files exist yet.

An ADR is written only after a real decision has been made with alternatives consciously evaluated — not backfilled for technology choices simply because they were mentioned in earlier planning documents.
