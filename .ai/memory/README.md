# .ai/memory/

Purpose: living project context — current state, roadmap-in-progress, glossary, known issues, decisions in progress. These files are updated over time and read at the start of new sessions.

Distinct from `.ai/sessions/`, which is an immutable historical log — `memory/` reflects the current state only.

The memory file structure is defined in **ERP-005 — Project Memory Framework**: four living files, split by concern rather than one large file, each updated in place as state changes.

- `current-state.md` — what exists right now and what's planned next
- `glossary.md` — operating-system and domain terms
- `known-issues.md` — known problems or gaps
- `decisions-in-progress.md` — open questions not yet resolved into an ADR
