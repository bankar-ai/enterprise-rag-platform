# ERP-014 — BM25 Hybrid Retrieval

Status: Done
Depends On: ERP-012

## Description

Adds BM25 full-text retrieval as a second retriever alongside the existing FAISS vector search, fused via Reciprocal Rank Fusion (RRF), so `POST /retrieval/query` becomes a hybrid semantic + lexical search instead of vector-only. BM25 uses Postgres's built-in full-text search (`tsvector`/`ts_rank`) over chunk text — no new service, consistent with the project's "avoid dependency bloat" rule. See `docs/superpowers/specs/2026-08-26-bm25-hybrid-retrieval-design.md` for the design, `docs/superpowers/plans/2026-08-26-bm25-hybrid-retrieval.md` for the implementation plan, and `.ai/adr/ADR-005.md` for the fusion-algorithm decision.

First of three deferred ERP-012 follow-ups, in order: BM25 hybrid retrieval (this ticket) → reranking (ERP-015) → PageIndex-style structure-aware retrieval (ERP-016).

## Acceptance Criteria

- [x] `chunks` table gains a generated `search_vector` (`tsvector`) column plus a GIN index, added via a new Alembic migration mirroring the existing migration's style
- [x] `app/ingestion/repository.py` gains a full-text search method returning `(vector_id, rank)` pairs, nearest-first, mirroring `FaissIndex.search`'s shape
- [x] `app/retrieval/service.py` fuses BM25 and vector ranks via Reciprocal Rank Fusion (RRF, `k=60`) into a single ranked result list
- [x] Existing `POST /retrieval/query` request/response contract is unchanged (additive only) — no new required fields, existing ERP-012 tests keep passing unmodified in behavior (though scores now reflect RRF, not `1/(1+distance)`)
- [x] Empty index and empty full-text match both degrade gracefully (fusion runs on whichever retriever(s) returned hits; never errors)
- [x] All new/modified modules covered by tests meeting the 90% coverage gate; BM25 and vector calls exercised for real against test Postgres/FAISS, embedding calls mocked

## Notes

Reranking (ERP-015) and PageIndex-style retrieval (ERP-016) are deliberately out of scope here and layer on top of this ticket's fused candidate list.
