# ERP-028 — Observability

Status: Done
Depends On: None

## Description

Adds distributed tracing and metrics across the RAG pipeline, closing the "Observability" item named as a project goal in `docs/architecture.md`. OpenTelemetry is the single instrumentation layer (traces + metrics), auto-instrumenting FastAPI/SQLAlchemy/Redis/httpx and hand-instrumented at the RAG-specific pipeline stages (embedding, FAISS, BM25, RRF fusion, rerank, section expansion, LLM generation) that auto-instrumentation can't see. Traces export to Jaeger, metrics to Prometheus/Grafana, all new local `docker-compose` services. Logs are trace-ID-correlated for pivoting from a log line to its trace.

## Acceptance Criteria

- [x] `app/core/telemetry.py` configures global tracer/meter providers and auto-instruments FastAPI, SQLAlchemy, Redis, and httpx (the `ollama` client's transport)
- [x] `app/core/logging_config.py` injects the active span's trace ID into every log record via a `logging.Filter`
- [x] Custom spans: `embedding.generate`, `faiss.search`, `bm25.search`, `retrieval.fuse`, `retrieval.rerank`, `retrieval.expand_sections`, `llm.generate`
- [x] Custom metrics: `embedding_cache_requests_total{result}`, `retrieval_cache_requests_total{result}`, `llm_generation_duration_seconds`, `ingestion_jobs_total{status}` (HTTP rate/latency come free from FastAPI auto-instrumentation)
- [x] `/metrics` mounted and unauthenticated (aggregate counts only, no per-request data), scraped successfully end-to-end by a real local Prometheus (verified: target reports `up`)
- [x] `docker-compose.yml` gains `jaeger` (1.76.0), `prometheus` (v3.9.0), `grafana` (13.2.0) services; Grafana auto-provisions both datasources and a 6-panel dashboard (verified via Grafana's API)
- [x] Telemetry setup never blocks app startup or request handling: `configure_telemetry` swallows its own setup exceptions, and an unreachable OTLP endpoint doesn't prevent the app from serving requests (both covered by tests)
- [x] All new tests use OTel's in-memory test fixtures (`InMemorySpanExporter`, `InMemoryMetricReader`) — no real Jaeger/Prometheus dependency for CI
- [x] `ruff`, `mypy --strict`, and `pytest-cov --cov-fail-under=90` all pass (276 passed, 99.05% coverage)
