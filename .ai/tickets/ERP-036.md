# ERP-036 — Fix Silent Score-Parse Failure in Generation Evaluation Judge

Status: Backlog
Depends On: None

## Description

`app/evaluation/judges.py`'s `OllamaLLMClientJudge` (the non-Ragas fallback judge from ERP-030)
silently scores a metric `0.0` when it cannot parse a numeric score out of the judge LLM's response,
rather than retrying or surfacing the failure distinctly from a genuinely bad answer. Verified live
(2026-09-07): a real evaluation run against `gemma3:4b` produced

```
Could not parse a numeric score for answer_relevancy from judge response: ''
Could not parse a numeric score for context_precision from judge response: ''
```

for one of four queries, and that query's `answer_relevancy`/`context_precision` scores were
recorded as `0.00` in the run summary -- indistinguishable in the persisted `generation_evaluation_runs`
row from an answer the judge genuinely rated as 0. This makes the evaluation harness itself
unreliable: a `0.0` score cannot currently be trusted to mean "bad answer" versus "judge LLM
returned an empty/unparseable response."

## Acceptance Criteria

- [ ] A parse failure is either retried (bounded, e.g. once) before falling back, or recorded as a
      distinct sentinel (e.g. `None`/NaN, not `0.0`) so it's visibly different from a real low score
      in `generation_evaluation_runs` and in the CLI summary output
- [ ] The CLI summary (`uv run python -m app.evaluation.generation_run`) reports parse-failure counts
      separately from the mean score calculation, rather than folding them into the mean silently
- [ ] Regression test covering the empty/unparseable judge response case
- [ ] `ruff`, `mypy --strict`, and `pytest-cov --cov-fail-under=90` all pass

## Notes

Found in the same 2026-09-07 live verification session as ERP-034/ERP-035, while confirming
generation answer quality end-to-end against real Ollama. The underlying answers observed in that
run were good (faithfulness 1.00 on all 4 queries) -- this ticket is about the harness's own
reliability, not a regression in generation quality.
