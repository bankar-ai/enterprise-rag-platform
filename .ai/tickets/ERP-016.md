# ERP-016 — PageIndex-Style Structure-Aware Retrieval

Status: Done
Depends On: ERP-014, ERP-015

## Description

Adds an optional structure-aware retrieval mode over `POST /retrieval/query`'s results, using chunks' existing `section_path` metadata (from ERP-011's chunker). When enabled (`expand_sections: bool = false`), each ranked chunk's full section is surfaced by including its sibling chunks (same document, identical `section_path`) alongside it, so a caller/generator gets full section context rather than an isolated fragment. See `.ai/adr/ADR-007.md` for why a lighter-weight sibling-expansion approach was chosen over a full hierarchical-tree/reasoning-based PageIndex implementation, and `docs/superpowers/specs/2026-08-26-pageindex-structure-aware-retrieval-design.md` / `docs/superpowers/plans/2026-08-26-pageindex-structure-aware-retrieval.md` for the design and plan. Third and last of the three deferred ERP-012 follow-ups (BM25 hybrid retrieval → reranking → this ticket).
