# ERP-029 — Evaluation (Retrieval Quality)

Status: Done
Depends On: None

## Description

Adds a lightweight, standalone retrieval-quality evaluation harness for this repo — the retrieval half of the "Evaluation" project goal named in `docs/architecture.md`/`docs/roadmap.md`. Generation-quality evaluation (LLM-as-judge metrics) is deferred as a follow-up. This is explicitly **not** the future "LLMOps & Evaluation Platform" repo (see the generalized-platform design constraint added to `docs/architecture.md` on 2026-09-06) — it's understood to likely be replaced/integrated with that platform once it exists.

## Acceptance Criteria

- [x] A small hand-authored golden dataset (`app/evaluation/dataset.py`: 2 documents, 5 chunks, 4 queries) is defined as `Chunk`-shaped templates, not real PDF fixtures, since `document_id`/`chunk_id` are only stable once stamped by a run — not something a dataset author can hardcode ahead of time
- [x] Pure metric functions: `precision_at_k`, `recall_at_k`, `reciprocal_rank` (`app/evaluation/metrics.py`)
- [x] `app/evaluation/runner.py`'s `run_evaluation()` ingests the golden dataset via the real `embed_and_persist`, queries it via the real `retrieval.service.search()`, scores results, and persists a summary to a new `evaluation_runs` Postgres table
- [x] Runner is never load-bearing on the real app's data: always builds its own temp-file-backed FAISS index (never `settings.faiss_index_path`) and deletes all transient eval data (documents, chunks, the eval user) after each run — only the `evaluation_runs` summary row persists
- [x] `uv run python -m app.evaluation.run` CLI entrypoint prints a report; verified end-to-end against live Ollama and real Postgres (Precision@3=0.33, Recall@3=1.0, MRR=1.0 on the golden dataset; confirmed no stray rows left behind)
- [x] Not wired into CI as a gate (no established acceptable-threshold baseline yet) — `tests/evaluation/` runs like any other test module, using a fake embedding client (no real Ollama in CI, consistent with the rest of this repo)
- [x] `ruff`, `mypy --strict`, and `pytest-cov --cov-fail-under=90` all pass (291 passed, 98.21% coverage)
