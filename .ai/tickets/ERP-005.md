# ERP-005 — Project Memory Framework

Status: Done
Depends On: ERP-002

## Description

Define the memory file structure used in `.ai/memory/`, per the pointer left in `.ai/README.md` and `.ai/memory/README.md`. Unlike tickets, ADRs, and sessions — which are one-file-per-instance and need a reusable template — memory is a small fixed set of living files that get updated in place, so this ticket defines and directly populates the files rather than adding a template.

Four files were created, split by concern: `current-state.md`, `glossary.md`, `known-issues.md`, and `decisions-in-progress.md`.
