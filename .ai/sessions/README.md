# .ai/sessions/

Purpose: immutable summaries, one file per completed session or major milestone, capturing decisions, implementation, blockers, and next steps.

Distinct from `.ai/memory/`, which holds living context that gets updated in place — `sessions/` is an append-only historical log.

The session format is defined in **ERP-004 — Session Framework**. Use the template at `.ai/templates/session.md` to create new sessions, named `YYYY-MM-DD-<slug>.md`.

First entry: `2026-07-22-ticket-and-adr-frameworks.md`.
